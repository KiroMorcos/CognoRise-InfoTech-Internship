## 📌 About This Repository

This repository contains the projects I developed as part of my **Web Development Internship at [CognoRise Infotech](https://cognoriseinfotech.com/)**.

The projects started with internship assignments and evolved through additional features, improvements, and personal ideas, allowing me to explore different aspects of modern web development.

## 📂 Projects

### 1. 🌐 Personal Portfolio Website

A modern, responsive, and accessible personal portfolio website designed to showcase my projects, technical skills, certifications, and professional background.

**Key Features**
- Responsive design for desktop, tablet, and mobile devices.
- Interactive project filtering by technology and category.
- Dynamic light and dark themes with persistent preferences.
- Smooth scroll-reveal animations.
- Contact form with validation and spam protection.
- Accessibility-focused design with keyboard navigation and semantic HTML.

**Tech Stack:** HTML5 · CSS3 · JavaScript

🔗 **[Live Demo](https://kiromorcos.github.io/My-Portfolio-Website/)**

---

### 2. 📝 SimBlog – Notes & Blog Application

A browser-based note-taking and blogging application built with EJS templates, vanilla JavaScript, and LocalStorage, featuring a rich set of productivity tools and a responsive interface.

**Key Features**
- Create, edit, delete, and organize notes.
- Markdown support for formatted content.
- Autosaved drafts and undo functionality after deletion.
- Search, sorting, tagging, and note pinning.
- Grid and list viewing modes.
- JSON import and export for data portability.
- Dynamic light and dark themes.
- Keyboard shortcuts for faster navigation.
- Responsive interface optimized for different screen sizes.

**Tech Stack:** EJS · HTML5 · CSS3 · JavaScript · LocalStorage · Node.js · Express.js

🔗 **[Live Demo](https://kiromorcos.github.io/SimBlog/)**

---

### 3. ✅ TaskFlow – Full-Stack Task Manager & Time Tracking

A full-stack task management application that originated as a **Task Manager API assignment during my internship** and was extended with an integrated time-tracking system inspired by productivity tools such as Toggl Track.

**Key Features**

**Task Management**
- Complete task CRUD operations.
- Kanban board with drag-and-drop task management.
- List view, search, filtering, and sorting.
- Task priorities, deadlines, tags, and status management.
- Dashboard statistics and overdue task tracking.

**Time Tracking**
- Start and stop timers directly on tasks.
- Automatic timer switching between tasks.
- Persistent timers that survive page refreshes.
- Time tracking reports with daily and task-based breakdowns.
- Charts, session history, and tracked-time statistics.

**Authentication & Security**
- Secure registration, login, and logout.
- JWT authentication with rotating refresh tokens.
- HTTP-only refresh-token cookies.
- Password hashing using bcrypt.
- Role-based authorization and strict user data ownership.
- Input validation, rate limiting, and security headers.

**Automated Notifications**
- Due-date reminder emails.
- Forgotten-timer reminder emails.
- Automated notification scheduling and retry handling.

**Tech Stack:** HTML5 · CSS3 · JavaScript · Node.js · Express.js · MongoDB · Mongoose · JWT · bcrypt

## 🚀 Getting Started

To explore the projects:

1. Clone this repository:

   ```bash
   git clone https://github.com/KiroMorcos/CognoRise-InfoTech-Internship.git
   ```

2. Navigate to the project you want to explore.

3. Run:

    ```bash
    npm install
    ```

**Note:** SimBlog and TaskFlow require Node.js for their development workflows. TaskFlow additionally requires a MongoDB database.
