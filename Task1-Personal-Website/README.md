# 🌐 Personal Portfolio Website

> A modern, responsive, and accessible personal portfolio website built with clean HTML5, vanilla JavaScript, and modern CSS featuring smooth scroll reveal animations, interactive project filtering, and a dynamic light/dark theme switcher.

[![Live Demo](https://img.shields.io/badge/Live-Website-9b4819?style=for-the-badge&logo=vercel&logoColor=white)](https://kiromorcos.github.io/My-Portfolio-Website/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](LICENSE)

---

## ✨ Features

* **🎨 Dynamic Theme Customization:** Fully responsive light and dark mode preferences with persistent user settings stored via `localStorage`.
* **⚡ Interactive Project Filtering:** Real-time tag-based filtering system allowing visitors to seamlessly sort through projects by technology (Web Development, Backend, Java, Embedded Systems, C).
* **📱 Fully Responsive Design:** Fluid layouts optimized across all screen sizes (mobile devices, tablets, and high-resolution desktop displays) using modern CSS grid and flexbox.
* **✉️ Secure Contact Form:** Integrated validation logic with Formspree handling and built-in spam protection honeypot fields.
* **♿ Accessibility First:** Includes skip-to-content links, clear ARIA states, semantic HTML5 landmarks, and full keyboard navigation support.

---

## 🛠️ Tech Stack

### **Frontend & Core**
* **HTML5** (Semantic markup & accessibility)
* **CSS3 / Modern CSS** (CSS Custom Properties, Flexbox, Grid, Responsive Design)
* **JavaScript (ES6+)** (DOM manipulation, IntersectionObserver API, event delegation)

### **Fonts & Styling Assets**
* **Typography:** *Radley* (Serif headings) and *Carlito* (Sans-serif body text) via Google Fonts.
